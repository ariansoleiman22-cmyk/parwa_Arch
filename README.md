# Sorani Computer Architecture Quiz

Static quiz website built from the uploaded PDF question bank.

## Files

- `index.html` - main page
- `styles.css` - layout and visual design
- `app.js` - quiz data and interaction logic

## Publish on GitHub Pages

1. Create a repository on GitHub.
2. Upload these three files to the repository root.
3. In repository settings, enable GitHub Pages from the main branch root.
4. Open the published URL.

## Content Notes

- Interface text is in Kurdish Sorani.
- Questions, answer choices, and answers stay in the original English from the PDF.
- The site includes:
  - 50 multiple-choice questions
  - 6 written review items
  - topic-based practice
  - random order mode
  - score summary
  - mistake review
